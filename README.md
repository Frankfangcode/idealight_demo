# idealight_demo — 模擬展示版（前端 mock）

給老師與團隊試玩的**純前端模擬版**，與正式系統 `idealight_sdg` 完全分離：
沒有後端、沒有資料庫、不呼叫 OpenAI。所有「AI 回答」都是預先寫好的罐頭內容，
用打字動畫模擬真實對話節奏。

## 怎麼打開

直接用瀏覽器開啟 `index.html` 即可（雙擊就能跑，不需要 Apache）。
要放到伺服器上給手機測試，整個資料夾丟上去就能用，沒有任何相依。

## 這個 demo 要展示什麼（對應會議決議）

| 會議決議 | demo 對應 |
|---|---|
| **溫度當操弄因子** | 上方控制列可即時切換「低溫・嚴謹」／「高溫・活潑」。所有 AI 回答（角色訊問、小助手、回饋）都有兩種溫度版本，每則訊息上標示產生時的溫度，可對同一人重問比較差異。 |
| **實驗組 vs 控制組** | 控制列可切換。實驗組在回饋階段看到 AI 逐一判斷六人說法有無瑕疵＋批判思考引導；控制組只看到「作答已送出」。 |
| **AI 判斷瑕疵要保留**（Bethany） | 回饋階段核心就是逐一判定每人說法「合理／有瑕疵」並附判準。 |
| **右下角小助手機器人**（第三種操弄候補） | 浮動 🤖 按鈕，不主動介入，學生自行決定是否求助——對應「依求助頻率／品質事後分組」的構想。 |
| **自由提問 vs 固定問題** | 訊問聊天室同時提供「建議問題」按鈕與自由輸入框；自由輸入會比對到最接近的劇本回答，比不到就回角色的通用回應。 |

## 內容來源

第一關「B-9 空了」的角色、證詞、訊問題目取自正式版 `api/seed_cake.sql`；
兩種溫度的回答文案是為 demo 另外撰寫的模擬內容。

## 檔案

```
index.html    入口（單頁應用）
css/demo.css  樣式（電影諜報檔案風、手機優先）
js/data.js    劇本資料＋所有罐頭 AI 回答（低溫/高溫兩版本）
js/app.js     流程邏輯（案情→證詞→訊問→判斷→回饋＋小助手）
img/          AI 生成的場景背景（bg_*.jpeg）與人物照（char_1~6.jpeg）、小助手頭像（bot.jpeg）
```

要改文案只需要動 `js/data.js`。

## 背景動畫與影片

- 每個階段有專屬全畫面背景（`img/bg_案情鍵名.jpeg`），以 Ken Burns 慢速推鏡 40 秒循環，換階段時交叉淡入；`prefers-reduced-motion` 時停用動畫。
- **要換成真正的影片**：把同名 `.mp4`（無聲、循環用，建議 8–12 秒 H.264）放進 `img/`，例如 `img/bg_intro.mp4`。程式會自動嘗試載入，成功就從靜態圖切成影片，失敗則安靜維持靜態圖，不用改任何程式。
- 影片可用 KLING / MiniMax 等圖生影片工具，直接以對應的 `bg_*.jpeg` 當首幀生成，即可與靜態版無縫銜接。
- 人物照對應 `js/data.js` 的角色 `key`（`img/char_{key}.jpeg`），換人物照直接覆蓋同名檔案即可。
